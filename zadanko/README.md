Laboratorium Bootstrap — Instrukcja

Wprowadzenie

Witaj w laboratorium Bootstrap! W czasie tych zajęć nauczysz się podstaw używania najpopularniejszego frameworka CSS. Projekt zawiera przykładowe strony i ćwiczenia, które możesz uruchomić lokalnie.

Zawartość folderu

- `index.html` — Strona główna z hero i przykładowymi kartami.
- `o-nas.html` — Informacje o zespole (przykład karty i przycisku).
- `uslugi.html` — Lista usług, pokazująca dwukolumnowy układ responsywny.
- `kontakt.html` — Formularz kontaktowy z prostą walidacją klienta.
- `styles.css` — Wspólne style używane przez wszystkie strony.

Jak uruchomić

1. Otwórz plik `index.html` w przeglądarce (np. dwuklik lub: otwórz w przeglądarce z edytora).
2. Sprawdź działanie przycisków i nawigacji. Navbar korzysta z Bootstrap JS, który ładuje się z CDN.

Ćwiczenia (sugerowane dla uczniów)

1. Dodaj nowe karty na `index.html` i użyj ikon (Bootstrap Icons).
2. W `uslugi.html` dodaj obrazki i spróbuj zmienić układ na trzy kolumny dla większych ekranów (`col-lg-4`).
3. W `kontakt.html` podłącz prosty backend (np. Formspree) lub skonfiguruj wysłanie formularza do konsoli.
4. Wyodrębnij dodatkowe niestandardowe zmienne CSS w `styles.css` i eksperymentuj z paletą.

Materiały pomocnicze

- Dokumentacja Bootstrap: https://getbootstrap.com/docs/5.3/getting-started/introduction/
- Bootstrap Icons: https://icons.getbootstrap.com/

Powodzenia! Jeśli chcesz, mogę:
- dodać ikony do kart/usług,
- wyciągnąć style do SCSS i dodać prosty build (npm),
- przygotować wersję prezentacyjną (PDF) z ćwiczeniami.
